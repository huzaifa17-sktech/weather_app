🧑‍💻 Weather App 🌤️
A responsive and modern Weather App built using React.js. It allows users to check the current weather of any city by fetching data from an external weather API.

🚀 Features
🌍 Search weather by city name

📡 Real-time weather updates using API

📱 Responsive design (mobile-friendly)

🌡️ Displays temperature, humidity, wind speed, and weather conditions

🔍 Clean UI using modern React and CSS

🛠️ Tech Stack
React.js (Vite for faster development)

HTML5 & CSS3

OpenWeatherMap API (or whichever API you used)

JavaScript (ES6+)
